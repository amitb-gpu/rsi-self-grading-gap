# Notes
- solution.py follows CPython's algorithm (regex, _invalid_charrefs, _invalid_codepoints, longest-prefix fallback for names without ';').
- Weak spot: the html5 entity table (2231 entries) is only a from-memory subset (Latin-1, HTML4, many common and multi-codepoint names). Rare names that are missing stay as '&name;'.
- Decimal refs over 4300 digits raise ValueError (int limit), matching CPython 3.12.
- Legacy no-semicolon names: Latin-1 set plus amp lt gt quot AMP LT GT QUOT COPY REG.
- self_cases.json is generated by mk_cases.py (41 cases, expectations hand-written).
